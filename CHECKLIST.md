## 9. Решения агента

Принимай эти решения сам и объясняй их через результат для продукта:

- Разделение `website` (публичные страницы и SEO) и `webapp` (экраны после входа).
- Почта: Postbox для Yandex Cloud, Resend для остальных. Спрашивай об аудитории, не о почтовом сервисе.
- Хостинг — по таблице раздела «Деплой»; профиль Terraform, размеры ресурсов, необходимость HA и CDN.
- Монолитный backend на PostgreSQL; Redis-совместимый Pub/Sub — только для обмена в реальном времени между экземплярами.
- Локальный PostgreSQL через Docker Compose на любой ОС; нативная установка — только по выбору пользователя.
- Astro для `website`; Next.js — только при явном требовании ISR в стиле Vercel.
- Мониторинг: штатные уведомления провайдера; новые сервисы наблюдения — только после записанного инцидента, где логов не хватило.
- Библиотеки, файлы, имена, рефакторинг и объём проверок — по [AGENTS.md](AGENTS.md).

Принятые при переносе решения:

- Профиль участника (имя, фамилия, предприятие, город, личный QR-токен, дата согласия) лежит в таблице `users`, а не в отдельной: у каждого участника ровно один аккаунт.
- Баллы считаются одной таблицей `activity_log`; все суммы и рейтинг берутся из неё.
- Правила «одна награда за Полимер», «баллы за первые 3 связи» и «за первые 5 идей» выполняются под блокировкой участника в PostgreSQL (`acquireParticipantScoringLock`), а не триггерами базы.
- Токены QR станций никогда не уходят участникам. Их видит только администратор на странице `/admin/stations`.
- Согласие на обработку данных обязательно на сервере: регистрация без него отклоняется.
- Для маршрутов `/api/event/*` и `/api/hostess/*` общий большой лимит запросов на адрес: весь зал сидит за одним Wi-Fi.
- Хостес (роль `hostess`): персонал площадки. Администратор назначает роль уже зарегистрированному человеку на `/admin/users`. Хостес ищет участника по QR или по имени и начисляет баллы за станцию, которая не засчиталась (правила те же, что при сканировании, в журнале сохраняется, кто начислил: `activity_log.awarded_by_id`). Для помощи с регистрацией на экране хостес есть QR страницы регистрации: участник регистрируется сам и сам принимает согласие. Хостес не играет: у неё нет баллов, она не в рейтинге и не может сканировать.
